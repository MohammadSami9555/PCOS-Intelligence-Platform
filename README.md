## Overview

PCOS Intelligence Platform is a healthcare-focused web application concept built to support users in organizing their health information related to Polycystic Ovary Syndrome (PCOS).

The platform aims to provide a guided and user-friendly experience where users can document symptoms, menstrual cycle patterns, lifestyle information, and relevant health history.

The project is currently under development, with the frontend being built using React, TypeScript, and Vite. Backend services and intelligent health analysis capabilities are planned for future development.

## Features

### Current Frontend

- Responsive healthcare-focused landing page
- PCOS-related health information and assessment interface
- Clinical assessment and lifestyle questionnaire UI
- Features and platform workflow sections
- Health information safety disclaimer
- Modern UI with a clean, premium visual design

### Planned Features

- Automatic draft saving and assessment resume
- Secure user authentication and profile management
- Backend API integration
- Database storage for assessment responses
- Health history and progress dashboard
- PCOS-related educational resources
- AI/ML-assisted health information analysis
- Explainable AI insights for research purposes
- Optional medical image analysis workflow

## Getting Started

Follow these steps to run the frontend locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/PCOS-Intelligence-Platform.git
```

### 2. Navigate to the project

```bash
cd PCOS-Intelligence-Platform
```

### 3. Install dependencies

```bash
npm install
```

Windows PowerShell users can also run:

```powershell
npm.cmd install
```

### 4. Start the development server

```bash
npm run dev
```

Windows PowerShell:

```powershell
npm.cmd run dev
```

Open the local URL displayed in the terminal, usually:

```text
http://localhost:5173/
```
